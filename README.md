# Stock-Anaylsis

个人持仓股票的定时深度分析仓库。

## ⚠️ 定时分析任务（routine）每次运行的强制步骤

**必须同时读取以下两份输入文件，缺一不可**，并在报告中**并行输出两套内容**（互不替代）：

| 输入文件 | 管什么 | 对应的报告章节 |
|---|---|---|
| **`holdings.md`** | **已持有的钱**——成本价、持股数、仓位占比、风险偏好、止盈止损纪律、调仓记录、现阶段战术指令 | 持仓七维度分析 + 止盈执行表 + CIO 市场扫描 |
| **`observation.md`** | **还没买的票**——主线缺口补充池（A）、中长期埋伏池（B）、波段候选池（C）、常规观察名单 | **「观察池日报」**（每个交易日**开盘前**必出） |

主线定义：**① AI 硬科技（第一主线）② AI 应用 ③ 创新药**。

### 数据缺口的处理顺序（强制，四步走完才允许写"未找到"）
1. **行情接口**（qt.gtimg.cn 实时 + web.ifzq.gtimg.cn 日K）——价格/均线/量能/位置一律现算，不得估算；
2. **WebSearch 最新公开信息**——优先近 7 天，注明来源与日期；
3. **查本仓库历史报告 `deep_analysis_*.md`**——旧报告里往往已核实过该数据，可直接复用，但**必须标注原始报告日期 + "数据滞后，参考意义有限"**；
4. 前三步都拿不到 → **写入 `observation.md` 的「📋 待办台账」并逐期滚动**，直到补齐或作废。**禁止编造数字，也禁止让缺口无声消失。**

## 文件说明

- **`holdings.md`** — 持仓台账 + 战术指令（见上表）。若字段仍为"待填写"则按无该信息处理并在报告中提示。
- **`observation.md`** — 观察池台账 + 待办台账（见上表）。
- **`deep_analysis.md`** — 最新一期深度分析报告（由定时任务覆盖更新）。
- **`deep_analysis_YYYYMMDD.md`** — 按运行日期命名的历史快照，**永不覆盖**，供复盘与上述"数据缺口处理第 3 步"检索。
